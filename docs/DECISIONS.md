| 2026-10-13         | `size-limit` (web) von 100 kB auf 110 kB angehoben                                                                                                                                                                                                           | Markdown-Rendering (`react-markdown` + `remark-gfm`, XSS-sicher) kostet ~2,6 kB Brotli-Overrun; legitimer Kostenpunkt eines Kerner-Features – Budget bewusst erhöht statt Guardrail zu schwächen oder Code-Splitting einzuführen |
| 2026-10-13         | Voice als Python-Sidecar (`apps/voz`) statt TypeScript-Integration: TTS via `edge-tts` (Microsoft, Online), STT via `whisper` (OpenAI, lokal)                                                                                                                | Keine TS-Dependencies für ML-Modelle; Sidecar optional – ohne laufendem Sidecar bleibt Chat voll funktionsfähig; Edge-TTS benötigt keine API-Key; Whisper läuft offline und skaliert lokal (GPU/CPU)                             |
| 2026-10-13         | Hands-free-Modus: RMS-Noise-Floor-Kalibrierung (500 ms) + EMA-Schwellwert-Adaption statt fester Schwellwerte                                                                                                                                                 | Robust gegenüber Umgebungsgeräuschen; 3× Noise-Floor + min. 0.01 RMS verhindert False-Positives; EMA (α=0.05) gleitet langsam mit, reagiert nicht auf Sprung-Artefakte                                                           |
| 2026-10-13         | Anti-Self-Hearing: 500 ms Post-TTS-Cooldown + synchrones `isSpeakingRef` statt React-State                                                                                                                                                                   | TTS-Ausgabe wird vom Mikrofon mitgefangen (Echo-Loop); 500 ms geben dem Speaker-Buffer Zeit zu flush-en; Ref statt State vermeidet async Gap zwischen `setIsSpeaking` und dem 10-ms-Detection-Loop                               |
| 2026-10-13         | Sprachabhängige Acknowledgment-Phrasen aus `acknowledgments.json` (de/en/es, je 10 Phrasen) statt fester deutscher Phrase                                                                                                                                    | Mehrere Sprachen unterstützt; zufällige Auswahl verhindert monotone Wiederholung; JSON statt Code – Phrasen ohne Rebuild änderbar                                                                                                |
| 2026-10-13         | TTS-Retry bei HTTP 403/500 mit 500 ms Delay in `voiceClient.ts`                                                                                                                                                                                              | Edge-TTS-Token-Ablauf verursacht sporadische 403s; ein Retry mit kurzem Delay löst das Problem zuverlässig ohne komplexe Backoff-Logik                                                                                           |
| 2026-10-13         | StrictMode-Double-Effect-Guard: `processedTranscriptRef` in `Chat.tsx` statt `useRef`-Reset in `useVoice.ts`                                                                                                                                                 | React StrictMode (dev) ruft `useEffect` zweimal auf – ohne Guard würde `speak()` + `send()` für dasselbe Transkript zweimal ausgelöst; Ref-Guard ist deterministisch und ohne Timing-Risiko                                      |
